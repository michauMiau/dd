GET CONNECTED

  1. Hit NEW SECRET for a fresh 48-character secret.
  2. Read it with SHOW and write it into pumpkin.toml yourself, on the PASTE-YOUR-SECRET line.
  3. Restart the app afterwards so Pumpkin reads the new file.
  4. Publish the port in the Custom App so your browser can reach it: 25585:25585/tcp
  5. Press LINK.
[networking.management] enabled = true address = "0.0.0.0:25585" secret = "PASTE-YOUR-SECRET" allowed_origins = ["*"]

A * in allowed_origins lets any website open this socket. Your secret is the only thing between a stranger and your stop button. Do not reuse it anywhere else.

This page talks to Pumpkin over a plain WebSocket, JSON-RPC 2.0. Nothing gets stored. Your secret stays in this tab and disappears when you close the page.

CONNECTING FROM ELSEWHERE

To reach it through playit, point the tunnel at the Pumpkin container on port 25585 and leave Proxy Protocol off. Anyone with the secret can stop your server, so treat it like a password.

Status— Version— Protocol— Players online—

The management protocol has no stop method. It only subscribes to server/stopping, which the server sends when it is already going down. To stop the server, stop the Pumpkin app in TrueNAS. This button exists so nobody loses ten minutes looking for a stop that the API cannot do.

[+] what this can and cannot do

This panel cannot run server commands, because the management API has no method for that, in Pumpkin and in vanilla Minecraft alike. What it does is send your text to everyone in chat or on the action bar, and show the messages the server pushes back while you play.

A command like /tp NAME X Y Z still has to be typed in the game by a player with the right permission. Everything the server sends back, including chat replies, lands in the log above.
