FIRST LINK

  1. Press GEN to roll a 48-character secret. Press COPY TOML to put the whole block on your clipboard.
  2. Paste it into pumpkin.toml in the mc-server folder, replacing the PASTE-YOUR-SECRET placeholder. Then restart the app so Pumpkin re-reads the file.
  3. Publish the port in the Custom App compose so the browser can reach it: 25585:25585/tcp
  4. Press SHOW on the secret field to confirm it matches the file, then press LINK.
[networking.management] enabled = true address = "0.0.0.0:25585" secret = "PASTE-YOUR-SECRET" allowed_origins = ["*"]

* in allowed_origins lets any page open this socket. The secret is the only thing standing between a stranger and your server stop button. Never reuse this secret anywhere else.

The panel talks to Pumpkin over a plain WebSocket using JSON-RPC 2.0. Nothing is stored. The secret lives in this tab only and is gone when you close the page.

REMOTE ACCESS

If you expose this through playit, point the tunnel at the Pumpkin container address and port 25585. Leave Proxy Protocol off. Anyone holding the secret can shut the server down, so treat it like a password.
